## Main: A1 — composed engine step

**Goal.** One state and one step that compose the stages already proved separately, in the engine's block order, so that `D ≤ 1/25` is a consequence of `R ≤ 1` along the real orbit, not an assumption. Fold in wrap, the θ-range, and a block-order theorem. This is the model every later closed-loop statement needs. It does not prove locking (O1) and it does not handle float64 or heterogeneous-ω orbits.

**Statement sketch.** Introduce a single `EngineState` (current θ, delay queue of `D+1` slots, coherence accumulator `C`, weight matrix `B`) over a finite node type, and one `engineStep` whose block order matches `advance_state` at the locked engine L755–857:

1. `compute_R`: coherence input and EMA, as in `PhaseCoherence` (`coherenceInput` / `coherenceStep` / `reported`), reading θ, the oldest queue slot (`HistoryBuffer.historyTrace` / `ReachableQueue`; engine `history[0]` is oldest, L841–844 and L735), and the pairwise offset `(ω_i+ω_j)τ/2` (engine L735–739). Do not re-declare these; import them.
2. `stepM` on `B` with drive `D = (η+μ) reported(C') − μ` (`WeightUpdate.stepM_scalar_recurrence`, `MatrixForm.stepM`, `Capacity.gateM`). The gate is again the per-edge min of L811–812, not a per-cell factor.
3. Phase update from the **new** (post-gate) `B`: `θ ← θ + dt (ω + Σ_j B_ij sin(θ_j^{delayed} − θ_i))`, then wrap (`WrapBridge.wrapPhase` / `PhaseIncrement.wrapPhase`, engine L830–839).
4. Queue shift: append the new θ, drop the oldest (`HistoryBuffer.shiftAppend` / `ReachableQueue`).

Prove, reusing existing lemmas:

- The B part of `engineStep` equals `stepM p D B` with `D` built from `reported` of the updated `C`.
- From an engine-shaped start (the shape of `initialize_state`: `C = 0`, constant prehistory, `B ≥ 0` symmetric with zero diagonal and rows already ≤ cap), every later state satisfies: `B` symmetric, nonnegative, zero diagonal, rows ≤ cap; `‖C_ij‖ ≤ 1`; `reported ∈ [0,1]`; queue consistent (current θ equals the newest slot); `θ ∈ [0, 2π)`.
- **Derive** `D_ij ≤ η = 1/25` (and `D_ij ≥ −μ`) from `reported ∈ [0,1]`. Do not assume the bound. This is what makes the drive hypothesis of the H9b envelopes, when they land, a consequence along this orbit.
- A block-order theorem: `R` is computed before `B` changes (ERRATA E5 / AUD-RATELAW condition (c)); the coupling reads the post-gate `B`, not the pre-gate proposal.
- The wrapped orbit and a lifted (unwrapped) orbit give the same coupling and the same R input, and differ only by `2πℤ` per coordinate (`phasor_wrap`, `delayed_input_step`).

`TrajectorySafety.feedbackStep` takes an arbitrary feedback `F`. Do not treat a theorem about arbitrary `F` as a theorem about this step. Instantiating `F` with the engine's phase-driven `reported` is the point of the work.
