## 3. Admission contract and paper argument

### Explicit trust assumptions

Let `p` be a digest selected by the **caller from a separately trusted authority**,
not from the supplied directory/manifest, a self-claimed id, an adjacent registry
or child consistency. The guard requires exact manifest bytes to match `p`
**before calling the existing validator**. Then it returns that validator's exact
object, retaining all existing child-hash/schema checks. A post-check detects
persistent manifest changes during delegation; it is **not atomic I/O**.

This does not create trust out of a hash. If the caller chooses the wrong,
self-derived, stale or attacker-controlled `p`, the policy is wrong. S01-only
integration must use an independently accepted ART-2217/root record; future runs
need an explicit independently issued profile. Test fixtures below use deliberately
local synthetic authority issuance and cannot certify their invented values.

### Paper argument — conditional, not Lean-compiled or race-safe

Assume the caller's expected manifest bytes are trustworthy, inputs stay unchanged
through the check/use interval, and the digest binding assumption holds. A matching
manifest digest binds its output declarations to those trusted bytes. The unchanged
validator then binds each of the four children to its trusted declaration. A
self-consistent replacement root cannot authorize replacement children without
changing the trusted root bytes (or violating the digest assumption). Rejecting
before delegation prevents even a successfully parsed replacement cohort from
being admitted by this boundary.

Thus root authentication plus retained child checks supplies **static byte lineage**
under those assumptions. It does not prove engine/physical origin, scientific
outcomes, source validity, successful baseline recomputation or all certificate
lineage semantics. A root that blesses bad content is still bad; the retained
validator must still reject invalid supported schemas. Our controls test that.

Exact-byte pinning intentionally rejects a whitespace-reserialized manifest even
if its JSON object is unchanged. Path relocation with identical bytes is allowed.
This follows the chosen authority-byte contract, not a generic logical-JSON
comparison or version/copy preference. No numerical tolerance is introduced.

### Narrow new-file implementation

`anchored_admission.py` has no repository imports. It takes explicit inputs,
external expected digest and validator callback; configuration errors have a
distinct type. Normal execution delegates to the actual imported `validate_run`.
Nothing is wired into current CLI/run_analysis; the guard is a review companion.
Do **not** perform a standalone preflight and then label an unchanged CLI run as
an installed/race-safe repair. Authorized future integration must thread trusted
admission through the real analysis boundary and decide immutable-input handling.

"""New-file caller-anchored admission proposal, not an installed authority.
The caller must trust the anchor independently of the supplied input directory.
Static-input byte admission only: no physics proof or atomic/TOCTOU guarantee.
"""
import hashlib
from pathlib import Path
import re


class TrustConfigurationError(ValueError):
    """Missing/malformed caller policy is a configuration blocker, not a negative."""


class ManifestTrustError(ValueError):
    def __init__(self, code='manifest_not_anchored'):
        self.code=code
        super().__init__(code)


def require_manifest_anchor(path, expected_manifest_sha256):
    if not isinstance(expected_manifest_sha256,str) or re.fullmatch('[0-9a-f]{64}',expected_manifest_sha256) is None:
        raise TrustConfigurationError('An independently selected lowercase SHA256 anchor is required')
    digest=hashlib.sha256()
    with Path(path).open('rb') as stream:
        for block in iter(lambda:stream.read(1024*1024),b''):
            digest.update(block)
    observed=digest.hexdigest()
    if observed!=expected_manifest_sha256:
        raise ManifestTrustError()
    return observed


def validate_anchored(inputs, *, expected_manifest_sha256, validate_run):
    """Require the external root BEFORE delegating to unchanged validate_run.
    Return its exact object; its child-hash/schema checks are never replaced.
    The post-check is only a persistent-manifest-change tripwire, not atomic I/O.
    """
    require_manifest_anchor(inputs.manifest,expected_manifest_sha256)
    result=validate_run(inputs)
    try:
        require_manifest_anchor(inputs.manifest,expected_manifest_sha256)
    except ManifestTrustError as error:
        raise ManifestTrustError('manifest_changed_during_validation') from error
    return result
